The Complete Guide to Mining on RustChain: Hardware Fingerprinting & Node Setup

By Le Nguyen Huy Hoang (@huyhoang2k5) · 850+ words · Hands-on Node Operator Guide

Unlike conventional cryptocurrencies where mining requires industrial GPU server racks or ASIC arrays, RustChain introduces a lightweight, physical hardware consensus protocol called Proof of Antiquity (PoA / RIP-200). In RustChain, an authentic, physical CPU from 2003 actually out-earns a modern datacenter virtual machine.

In this comprehensive walkthrough, you will learn the exact steps to generate a wallet, configure a node, verify silicon antiquity, and start participating in the RustChain decentralized ecosystem.

1. The Core Idea: Proof of Antiquity (PoA)

Proof of Antiquity turns hardware physics into cryptographic consensus. Instead of burning terawatt-hours finding SHA-256 collision preimages, a node proves two things:

  1. Physical Presence: It is running on real silicon, not an emulated hypervisor (QEMU/KVM/Docker).
  2. Hardware Antiquity: The older the verified CPU design, the higher its multiplier tier.

2. Step-by-Step Node & Miner Setup

Step 2.1: Environment Prerequisites

RustChain miners run natively on Python 3.9+ across Linux, macOS, and Windows. Clone the official repository and inspect the codebase:

# 1. Clone the core repository
git clone https://github.com/Scottcjn/Rustchain.git
cd Rustchain

# 2. Install the lightweight CLI package
pip install clawrtc beacon-skill

Step 2.2: Generate Your Canonical Ed25519 Wallet

RustChain uses Ed25519 keypairs for zero-overhead identity verification. Generate a new wallet keypair:

clawrtc wallet create --name my-miner-wallet

This outputs your 40-character hexadecimal wallet address (starting with RTC...) and stores your private credentials locally. Keep your seed phrase secure.

Step 2.3: Dry-Run Verification

Before connecting to the live block gossip network, verify your local hardware attestation payload using --dry-run:

python miners/linux/rustchain_linux_miner.py --dry-run --show-payload --verbose --wallet YOUR_WALLET_ADDRESS

The dry-run analyzes your CPU's L1/L2 cache latency curves, branch execution delays, and clock jitter. If your hardware is authentic physical silicon, the payload will report an antiquity classification score ready for network attestation.

Pro Tip on Config Paths: If you installed via curl -sL https://rustchain.org/install.sh, your configuration is located at /opt/rustchain-miner/config.json. If installed from the repository clone via setup.sh, it is stored in ~/.rustchain/config.json. Ensure your service supervisor references the correct directory.
